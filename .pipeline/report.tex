\section{Project Overview}

I implemented Gaussian Naive Bayes and Linear Discriminant Analysis (LDA) to classify Jira bug tickets and silicon defects. Both algorithms effectively modeled class distributions. I achieved accuracies of 87.50\% and 85.70\%, showcasing their power in practical settings.

\textbf{Naive Bayes:} Uses Bayes' theorem under the independence assumption.

\textbf{Gaussian Naive Bayes:} Assumes features follow a Gaussian distribution for each class.

\textbf{LDA:} Finds feature combinations that maximize class separation.
